> **Planned for Monosecret 0.2+:** Source and local tests are integrated, but
> NuGet publication remains deferred. Installation commands show the intended
> workflow after the package is released.

The C# SDK (`Monosecret`) is a thin client over the same Rust resolver as
the CLI. Every provider, fallback chain, profile, generator, reference, and
`as_path` secret therefore works without C#-side resolution logic.

## Install (planned for 0.2+)

```bash
$ dotnet add package Monosecret
```

The planned package targets .NET 8 and will include native resolvers for glibc and musl
Linux x64/Arm64, macOS x64/Arm64, and Windows x64/Arm64. Windows assets
statically include the C runtime. No separate Monosecret CLI, native library,
Visual C++ Redistributable, or system `libdbus` installation is needed.

The managed client is safe to trim and supports NativeAOT publishing. A
NativeAOT application still carries the matching Monosecret native resolver
beside its executable; `dotnet publish` selects and copies that runtime asset
automatically.

```bash
$ dotnet publish -c Release -r linux-x64 --self-contained \
  -p:PublishAot=true
```

## Native loading

The NuGet runtime asset is selected automatically. For local SDK development,
`MONOSECRET_FFI_LIB` can point to a particular `libmonosecret_ffi` build. From
a Monosecret source checkout, the SDK also searches an ancestor Cargo
`target/debug` or `target/release` directory.
