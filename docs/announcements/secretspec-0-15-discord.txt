🚀 SecretSpec 0.15 is out!

The feature we’re most excited about is provider credential chaining.

A secret store usually needs a secret of its own before it can open. SecretSpec can now fetch that credential from another provider. For example, a Bitwarden access token can come from your OS keyring, Vault AppRole credentials from 1Password, or Azure service principal credentials from a local store.

Credentials are passed directly to the destination provider in memory. They never need to be exported into your application environment. The bootstrap chain is intentionally limited to one hop, keeping it understandable and preventing circular dependencies.

We also added:

• Azure Key Vault and Gopass providers
• A PHP SDK for PHP FPM, Laravel, Symfony, and CLI apps
• secretspec export for shells, JSON, dotenv, and GitHub Actions
• AWS Secrets Manager KMS and creation guardrails for tags
• More predictable lazy provider fallback chains
• Several profile, validation, and compatibility fixes

This is one of those releases where SecretSpec feels noticeably more complete. We’d love to hear what you build with it.
