The Node.js / TypeScript SDK (`secretspec`) is a thin wrapper over a
[napi-rs](https://napi.rs/) native addon that embeds the resolver. Resolution
happens in the Rust core, so the SDK inherits every provider with no JS-side
logic. npm installs a prebuilt addon for the host platform: Linux x64 and
arm64 (glibc, and musl for Alpine images in 0.20+), macOS on Apple silicon, and
Windows x64. TypeScript declarations ship in `index.d.ts`.

## Caller context {/* #caller-context-020 */}

<VersionCompatibility version="0.20" />

```js
const builder = SecretSpec.builder().withCaller({
  name: 'git',
  version: '2.51.0',
  operation: 'credential_get',
  resource: 'github.com',
});
```

Caller context identifies the invoking integration in audit records but never
satisfies `require_reason`. Do not put credentials or secret values in it.

## Inline specifications {/* #inline-specifications-020 */}

<VersionCompatibility version="0.20" />

Use `.withInlineSpec(spec, baseDir)` (or `loadAsync`/`reportAsync`) to resolve a
strict inline-spec v2 object (SecretSpec 0.21+). `baseDir` resolves relative
provider paths; the embedded addon submits the versioned native request directly.

## Files (`as_path`)

<VersionCompatibility version="0.22" kind="changed">

`as_path` uses private temporary files by default. Set
`SECRETSPEC_FILE_STORAGE=file-lease` to opt into process-owned, memory-backed
files on Linux and macOS (0.22+). This mode requires the matching `secretspec`
executable beside the application or on PATH; `SECRETSPEC_BIN` selects it.
Linux leases require sufficient `RLIMIT_MEMLOCK`. Explicit lease failures and
unsupported platforms return errors without a disk fallback.

SDK cleanup releases visible files and hidden composition dependencies for
either backend. Temporary files must be explicitly cleaned up; they are not
revoked automatically on process exit. See
[file delivery and lifetimes](/reference/configuration/#as_path-option).

</VersionCompatibility>

Keep the result alive while consuming its paths, and call the SDK's cleanup
method afterward. Temporary files remain until explicit cleanup. With `file-lease`, unreleased
files are revoked when the embedding process exits.
