🚀 SecretSpec 0.18 is out!

This release fills in the secret lifecycle around the declarative manifest:

• `secretspec add` adds a declaration without storing a value
• `secretspec delete` removes stored values without changing the declaration
• `secretspec import --delete-source` verifies the destination before removing the source
• `secretspec init --from` can discover declarations in age files, AWS Parameter Store hierarchies, and Bitwarden collections

We also added four providers:

• Bitwarden Password Manager via the `bw` CLI
• Keeper Secrets Manager via Keeper’s official Rust SDK
• AWS Systems Manager Parameter Store with encrypted `SecureString` values
• Read-only Dashlane access via `dcli`

Swift joins the SDK family on macOS, using the same shared resolver as the CLI and every other SDK. Vault and OpenBao now support custom AppRole/JWT mounts, AppRoles without SecretID binding, and server-default JWT roles.
